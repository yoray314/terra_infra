= Azure Infrastructure Examples with OpenTofu

This repository is a progressive, bottom-up collection of Azure infrastructure examples using
OpenTofu. Each example should be small enough to understand in isolation while demonstrating the
same engineering practices expected in a shared infrastructure repository.

== Goals

* Explain infrastructure concepts before introducing abstractions.
* Keep examples reproducible, reviewable, and safe to destroy.
* Add reusable modules only after an example demonstrates a concrete need for them.
* Apply consistent Git, documentation, and validation practices from the first change.

== Current Status

Repository standards and the development toolchain are established. The examples progress from a
local-state resource group through remote state, secret infrastructure, identity, CI/CD, and reusable
environment composition.

== Getting Started

. Install and verify the tools in link:docs/toolchain.adoc[Development Toolchain].
. Follow link:CONTRIBUTING.adoc[Contribution and commit guidelines] to enable local checks.
. Confirm the intended Azure account and subscription before running an example.
